# Análisis exploratorio de vehículos en Estados Unidos.

Proyecto de análisis exploratorio de datos sobre vehículos usados en Estados Unidos, enfocado en identificar factores que influyen en el precio, la demanda y el tiempo de venta de los automóviles.

## Herramientas usadas
- Streamlit → Crear la interfaz web
- Python → Procesar datos
- Pandas → Manipular datos
- GitHub → Versionar el código
- Render → Publicar la aplicación en internet

## Requisitos

- Python 3.11+
- Dependencias en `requirements.txt`
- Repositorio en [Render.com](https://render.com)

## Estructura del Proyecto

```
├── app.py                 # Aplicación principal de Streamlit
├── requirements.txt       # Dependencias del proyecto
├── render.yaml           # Configuración para Render
├── data/
│   ├── raw/             # Datos sin procesar
│   └── processed/       # Datos procesados
├── src/                 # Código reutilizable
└── assets/              # Imágenes y recursos
```
